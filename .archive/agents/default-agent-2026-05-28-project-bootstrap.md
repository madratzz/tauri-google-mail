# Archived Default Agent Profile

Archived on: 2026-09-14
Source date: 2026-05-28

## Historical Role

The default agent maintained and extended the Gmail Desktop Tauri 2 application, including features, bug fixes, icon assets, release workflow, and agent context.

## Historical Operating Guidance

- Read active context, memory, learnings, and logs before work.
- Update context files after meaningful work and archive older material before removing it from active files.
- Do not store secrets, credentials, tokens, passwords, or private keys.
- Preserve the documented WebView2 protections: asynchronous navigation handling, stored peek URLs, and forced window destruction for reliable close behavior.

The profile was superseded to incorporate the repository-wide policy now defined in `AGENTS.md`.
